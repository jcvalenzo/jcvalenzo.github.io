# Portafolio de Juan Claudio Valenzuela Ortega

Sitio estático en español, con NES.css y estética retro. Está listo para publicar en GitHub Pages.

## Publicarlo en GitHub Pages

1. Sube el contenido de esta carpeta al repositorio donde publicarás el sitio.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona la rama principal y la carpeta `/ (root)` como origen, y guarda.

La página carga el perfil desde `data.json`. Cambia el archivo cuando quieras agregar el enlace de GitHub, proyectos públicos, avatar u otros datos. El usuario de GitHub no se inventó porque no estaba indicado en el material recibido.

## Archivos

- `index.html`: estructura accesible de la página.
- `css/style.css`: diseño responsive, NES.css y estilos retro.
- `js/main.js`: renderizado del perfil desde el JSON.
- `data.json`: contenido profesional editable.
